# SCM ONE APP 2.0
Built by Team FM

## Deploy to GitHub Pages
1. Create new repo on GitHub: `scm-one-app`
2. Upload all files from this folder to repo root
3. Go to Settings > Pages > Source: main branch / root
4. Save - your app will be live at https://yourusername.github.io/scm-one-app/

## Features
- Staff Portal: Vehicle Routes, Stock Transactions, Load Crates, Route Assignment, Driver Dashboard
- Driver Portal: Trips, Route Indent, Delivery with crate tracking, Return to Plant
- PWA ready with icon
